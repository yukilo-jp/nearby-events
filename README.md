# Nearby Events

関東・甲信越・南東北の公開イベント情報を、出典と確認日を付けて配信するための保存先です。初期版は市貝町周辺の確認済み情報から始めます。全国・対象13都県の網羅的な一覧ではありません。

## 配信

- `events.json`: アプリが読む公開JSON。座標・日時・公式URL・出典・確認日を収録します。
- `sources.json`: 発見・照合に使う情報源。閲覧可能な公開ページのみを利用します。
- `UPDATE_GUIDE.md`: 定時更新の調査・検証手順。
- 端末の現在地・利用履歴・個人情報・認証情報は保存しません。

アプリ側で位置情報の許可を受けて現在地を取得し、直線距離・北を上とした8方向を計算します。GPSが取得できない場合は市貝町役場基準であることを表示します。会場座標が確認できていないイベントは半径検索から除外します。

イベントの収集は毎日、アプリの配信データ取得は約1時間ごと・アプリ起動時・端末再起動時です。端末の省電力制限や通信状態により取得は遅れることがあります。移動中の自動位置更新にはAndroidの「常に許可」が必要です。

## 情報の取り扱い

ふらっとろーかるなどの地域情報サイト、自治体、観光協会、会場・主催者の公式ページを組み合わせます。各情報源の利用条件とアクセス制限に従い、アクセス制限を回避しません。本文・画像の転載をせず、事実情報と独自の短い概要、元ページへのリンクを収録します。本文の内容・開催の有無・時刻・申込条件は公式ページでご確認ください。

画像や記事本文の著作権は各権利者に帰属します。この保存先が元記事を自由に再利用できる権利を付与するものではありません。

## 更新実行環境

このチャットに紐づくCodexの定時実行で調査・更新します。有料APIは使用しませんが、ChatGPT/Codexの契約・利用枠・接続権限の範囲内で動作します。ローカル実行のため、Macの電源とCodexアプリの起動が必要です。無人実行で承認が必要になった場合は停止し、その旨を通知します。
